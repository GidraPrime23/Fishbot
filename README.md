# FishBot (Android) — авто-рыбалка по картинке

Приложение само видит экран (захват экрана), находит поклёвку и мини-игру и нажимает/удерживает кнопку рыбалки
(через службу спецвозможностей). ПК не нужен.

## Сборка APK
**Без ПК:** создай репозиторий на GitHub, залей туда содержимое этой папки, вкладка Actions → Build APK → Run workflow →
скачай артефакт `FishBot-apk` → внутри `app-debug.apk`.
**Android Studio:** открыть папку, Build → Build APK(s).

## Первый запуск
1. Установи APK. Шаг 1: разрешение «поверх других окон».
2. Шаг 2: включи службу «FishBot» в спецвозможностях (Android 13+: сначала Настройки → Приложения → FishBot → ⋮ → «Разрешить ограниченные настройки»).
3. Шаг 3: «Запустить», разреши запись экрана.
4. Открой игру (ландшафт), встань у воды с удочкой. На панели FishBot нажми ⌖ и коснись кнопки рыбалки (один раз).
5. Нажми ▶. Панель можно таскать за таймер. ❚❚ — пауза, ✕ — выход.

## Как работает
- Поклёвка: оранжевый значок «!» у кнопки.
- Мини-игра: зелёная (поплавок в зоне) или коричневая (вне зоны) полоса + жёлтая линия поплавка; бот держит кнопку, пока линия ниже центра зоны, и отпускает, когда выше.
- Нет поклёвки N раз подряд → стоп и сирена.

## Проверка зрения без телефона
`tools/VisionTest.java` гоняет ядро `Vision.java` по кадрам видео:
`javac -d out app/src/main/java/com/fishbot/Vision.java tools/VisionTest.java && java -cp out VisionTest <папка_png> <fps> <btnX> <btnY>`

## Подстройка
Если поплавок «дёргается» или опаздывает: `kd` в `Vision.Controller` (по умолчанию 0.12; больше = раньше тормозит).
